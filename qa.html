5. Human acceptance matrix

6. Negative, offline, and recovery testing

Offline limitation: Loading this GitHub Pages workbench requires a network. To test the standalone requirement, save each HTML independently, disconnect the network, open it with file://, and complete representative gameplay. For local WebP mode, download and extract the repository ZIP and repeat with the network disconnected. Only manual execution can confirm those paths.

7. Review coverage and release decision

Review setup, tutorial, planning, auction, build, submit, debrief, and closed screens for both roles; verify both languages, keyboard-only, pointer-only, touch-only, 200% zoom, 320px reflow, reduced motion, focus and status announcements. Check number formats, invalid inputs, recovery, and the original instructor/student independence.

No release acceptance is inferred from this workbench. Functional and human QA remain pending until explicitly observed.
