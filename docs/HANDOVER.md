## 2. What works

- **Build and CI.** `npm run verify` runs typecheck, lint, unit tests, the build check and Playwright over `file://` in Chromium, Firefox and WebKit. CI runs Windows and Ubuntu on Node 22 and 24. `dist/index.html` is about 0.7 MB, deterministic, with a hash-pinned CSP and embedded notices.
- **Rules** (`source/domain/`): all of MPES §6, with schema-3 validators and backup envelope v1. Tests compare data and deal vectors with the MPES text; 12 backups generated by the 4.1.0-dev.1 domain import unchanged (`tests/fixtures/legacy/`); a property test checks that every reachable state equals its ledger replay.
- **Interface** (`source/ui/`, `source/app/`): instructor console and student companion for all eight phases in EN/FR, keyboard bidding, state-bound confirmations, private submission mode, export/import with undo, designed degraded states, gap meter, card impact preview, per-card score contribution at debrief.
- **Art and bay** (`source/ui/art.ts`, `source/bay/`): 77 original SVG illustrations (decision D-02, MIT) in one theme-aware style; a stylised Three.js vehicle per mission with a visible part per card, orbit, exploded view, render on demand and a quiet WebGL fallback.
- **Journeys:** `journey-en` (J1/J3/J5), `journey-fr` (J2, shared award), `recovery` (J4), `rehearsal` (G-PILOT substitute, S1–S5 all PASS), `art` (RQ-22/23), `perf` (RQ-26), `slice`, `chooser`. Every page runs with a network guard (J7). Amounts are checked against the independent oracle in `tests/e2e/oracle.ts`. Last full run: 134 unit and 44 browser tests PASS (4 engine-specific skips).
- **Docs:** classroom quick start and recovery guide (EN/FR); `tests/unit/docs.test.ts` keeps the guide's control names in step with the interface.
