## 2. What works

- Repository bootstrapped from `origin/main`; the old tree is removed on this branch only.
- Pinned toolchain: TypeScript 6.0.3 (strict), esbuild 0.28.2, Vitest 5.0.1, Playwright 1.63.0 with axe-core 4.13.0, ESLint 10.10.0, three 0.186.1.
- `npm run build` produces only `dist/index.html`, deterministically, with a hash-pinned CSP, embedded licence and notices, an LF check on inputs and an 8 MB limit. `npm run check` verifies the committed file.
- Bilingual role chooser with About/licences dialog.
- Domain (`source/domain/`): canonical data generated from MPES Appendix A, bit-exact market deal, money, scoring, awards, ledger, instructor and student commands, schema-3 validators and backup envelope v1.
- MPES 2.1.1 corrects the ROUND reveal row (§6.5) to the original game's behaviour.
- Tests (Vitest, 130 PASS, domain line coverage 97.9%): `rules.test.ts` compares data and deal vectors with the MPES text; `saves.test.ts` imports 12 schema-3 backups generated by the 4.1.0-dev.1 domain (`tests/fixtures/legacy/`, incl. a 210-entry ledger and French text) and rejects 34 tampering cases; `instructor.test.ts` includes a fast-check property that every reachable state validates and equals its ledger replay; `student.test.ts`.
- App and UI: `source/app/` (controller validates every next state before commit; sessionStorage port with failure tolerance), `source/ui/` (shared shell with phase progress, menu, export/import with undo, state-bound confirmations; instructor console and student companion for all eight phases), `source/bay/` (placeholder Three.js bay, one persistent renderer, render on demand).
- M2 architecture decision: **GO** for HTML-first UI plus 3D bay. The slice journey (both roles, a full round with a void and corrected sale, reload, export/import into a fresh context, EN/FR switching with input kept, axe scans) passes in Chromium, Firefox and WebKit over `file://` with zero network requests.
- M3: instructor keyboard shortcuts, unsupported-browser notice, quiet WebGL probe (CI Firefox has no WebGL; PR #13's Ubuntu/Node 24 job failed on the console errors this caused, now fixed).
- Original illustration set (`source/ui/art.ts`, decision D-02): 70 cards, 6 vehicles and the practice card as themed inline SVG. Started early; M5 refines distinctness and frame overflow (FP-C, COM-E).
- E2E (37 tests × 3 engines): `chooser`, `slice`, `journey-en` (J1/J3/J5: 70 lots EN timed, pause/expiry/extend, unsold with leader, void+replacement, corrected sale, keyboard bidding, reloads incl. open lot restored paused, missed purchase reconciled, private submissions, award; every amount checked against the independent oracle in `tests/e2e/oracle.ts`), `journey-fr` (J2: 10 teams, French, MANUAL, untimed, from an imported fixed-seed backup, shared award), `recovery` (J4: storage denied, unreadable save, bad imports, legacy import paused, refused download, no WebGL). Every page runs with a network guard (J7).
- E2E list continues: `tests/e2e/chooser.spec.ts` and `slice.spec.ts` over `file://` in Chromium, Firefox and WebKit with network guard and axe.
