## 2. What works

- Repository bootstrapped from `origin/main`; the old tree is removed on this branch only.
- Pinned toolchain: TypeScript 6.0.3 (strict), esbuild 0.28.2, Vitest 5.0.1, Playwright 1.63.0 with axe-core 4.13.0, ESLint 10.10.0, three 0.186.1.
- `npm run build` produces only `dist/index.html`, deterministically, with a hash-pinned CSP, embedded licence and notices, an LF check on inputs and an 8 MB limit. `npm run check` verifies the committed file.
- Bilingual role chooser with About/licences dialog.
- Domain (`source/domain/`): canonical data generated from MPES Appendix A, bit-exact market deal, money, scoring, awards, ledger, instructor and student commands, schema-3 validators and backup envelope v1.
- MPES 2.1.1 corrects the ROUND reveal row (§6.5) to the original game's behaviour.
- Tests (Vitest, 130 PASS, domain line coverage 97.9%): `rules.test.ts` compares data and deal vectors with the MPES text; `saves.test.ts` imports 12 schema-3 backups generated by the 4.1.0-dev.1 domain (`tests/fixtures/legacy/`, incl. a 210-entry ledger and French text) and rejects 34 tampering cases; `instructor.test.ts` includes a fast-check property that every reachable state validates and equals its ledger replay; `student.test.ts`.
- E2E: `tests/e2e/chooser.spec.ts` over `file://` in Chromium, Firefox and WebKit with network guard and axe (12 PASS).
