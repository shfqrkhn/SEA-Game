**CI failure found and fixed (run 38089382489, the first CI run of the 3D tests):** on the GitHub runner's software WebGL, every Playwright action took 5–17 s once the model was showing, and 7 showcase tests timed out. The stage drew at 30 fps whatever a frame cost, and drew synchronously on every drag or key event. The fix, MPES §10.3 and `source/showcase/pace.ts`: a drawn frame is timed by the gap to the next animation frame, the next draw waits at least twice that (1 s at most), and every redraw goes through that one paced frame. Locally the failure did not reproduce, even with SwiftShader pinned to one core, so the runner is the oracle for this fix.
