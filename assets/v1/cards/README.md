# Card illustrations, version v1

Approved images use **<CARD-ID>.webp**. Required IDs: CAP-A..G, MOB-A..G, FP-A..G, PRO-A..G, COM-A..G, SA-A..G, ACC-A..G, and SE-A..U (70 files).

The HTML references these files directly by URL only when online. Missing or inaccessible images fall back to embedded SVG art. Do not embed gameplay rules, labels, prices, personal information, or tracking in image files. Prefer optimized 10:3 WebP images without baked-in text.

No images are approved/published yet. Do not treat samples as finalized card content. Use a new versioned directory for revisions after approval.
